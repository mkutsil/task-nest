# 📖 TaskNest

TaskNest is a web application for organizing tasks using a Kanban board.  
The project is designed to help manage workflows effectively: you can create tasks, drag & drop them between columns, open nested modals, attach files, and track progress.

## 🔑 Core Features

- Kanban board with columns: Todo, In Progress, Done
- Drag & Drop tasks between columns
- Task creation via modal (Formik + Yup)
- Nested modals for selecting an assignee
- File attachments for tasks
- Task storage in `localStorage` or via mock API
